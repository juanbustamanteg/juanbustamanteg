## Prototypes

**[Smart Retry](https://github.com/juanbustamanteg/belvo-smart-retry)** · [live demo](https://juanbustamanteg.github.io/belvo-smart-retry/)
Which loans to retry, when, and for how much. A collections decision tool that replaces blind payment retries with explainable rules. Replayed over historical challenge data: −60% debit requests and about 2× money collected per request. Unofficial product-challenge prototype, not production.

**[Smart Retry 2.0](https://github.com/juanbustamanteg/smart-retry-2)** · [live demo](https://juanbustamanteg.github.io/smart-retry-2/)
Visual redesign of the same MVP: same rules and data, new interface.
